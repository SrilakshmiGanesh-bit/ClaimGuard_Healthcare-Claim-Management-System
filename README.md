# ClaimGuard – Healthcare Claim Management System

ClaimGuard is a healthcare claim management application designed to manage patient information, validate medical data, and help reduce insurance claim errors.

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA & Hibernate
- MySQL
- Jakarta Bean Validation
- Maven
- Postman

## Features
- Create, view, update and delete patient records.
- Validate patient details using Jakarta Bean Validation.
- Handle missing patient records with appropriate HTTP exceptions.
- REST API development using Spring Boot.
- Database integration using Spring Data JPA and MySQL.

## Project Architecture

The application follows a layered architecture:

- **Controller:** Handles HTTP requests.
- **Service:** Implements business logic.
- **Repository:** Handles database operations.
- **Entity:** Represents database tables.
- **DTO:** Transfers request and response data.

## Future Enhancements
